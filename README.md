# 8-bit Arithmetic Logic Unit (ALU) | RTL-to-GDSII using OpenLane

## Overview

This project implements an 8-bit Arithmetic Logic Unit (ALU) in Verilog HDL and demonstrates the complete RTL-to-GDSII ASIC design flow using OpenLane with the SKY130 PDK.

## Features

- 8-bit Arithmetic Operations
- 8-bit Logical Operations
- Addition
- Subtraction
- AND, OR, XOR, NOT
- Functional Verification using ModelSim
- RTL-to-GDSII Implementation using OpenLane

## Tools Used

- Verilog HDL
- ModelSim
- OpenLane
- OpenROAD
- Yosys
- Magic
- KLayout
- SKY130 PDK
